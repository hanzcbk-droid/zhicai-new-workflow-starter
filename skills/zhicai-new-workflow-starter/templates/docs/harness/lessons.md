# 经验与候选规则 · Lessons

> 每犯一次错，都要变成以后能防住它的东西，但不直接往 AGENTS.md 里塞，免得说明书越写越长。

## 怎么用
- 出错并找到原因后，先在这里记一条，状态写"候选"。
- 同一类问题出现第 2 次，或者用户说"以后都这样"：提议把它升级成 AGENTS.md 的硬约束，用户同意后再写进去，状态改成"已升级"。
- 写之前先看看已有规则：能改一条旧规则覆盖的，就不新加。
- AGENTS.md 的硬约束超过 15 条时，提醒用户一起清理：哪些能合并、哪些已经用不上了。
- 模型变强以后某条规则用不上了：用户确认后，把状态改成"已作废"。
